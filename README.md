# Maestro Paints — Cloudflare Fixed Build

This build uses a FLAT repository structure: all HTML, CSS, JS, images and SVGs are in the repository root.
This avoids nested asset-path problems when deploying through GitHub → Cloudflare Workers/Pages.

## Upload
1. Delete/replace the old website files in the GitHub repository.
2. Upload ALL files from this ZIP directly into the repository root.
3. Commit.
4. Wait for the connected Cloudflare deployment to show Success.
5. Hard refresh the live site with Ctrl+F5.

Do not upload the ZIP itself.

## Included
Homepage, Products, Acrylic PVA detail, Colours, Our Story, Contact, Durban imagery, WhatsApp integration,
product images, logo, USP icons and responsive CSS/JS.

Technical product values that were not supplied remain marked for client confirmation.
