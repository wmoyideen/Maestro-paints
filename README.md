# Maestro Paints — final frontend design build

This is the approved static frontend build for GitHub / Cloudflare review before Shopify conversion.

## Key changes in this build
- Sharper, larger Maestro logo in header and footer.
- Bold CTA arrows used consistently across the site.
- Hero image edge blended into black; hero now fills the initial viewport so the USP strip begins below the fold.
- USP icons replaced with relevant line icons.
- Product packshots upgraded and set to `object-fit: contain` so buckets are not cropped.
- Removed the Browse by Category section from the homepage.
- Added a homepage enquiry section with Enquire Now and WhatsApp actions.
- Added WhatsApp links to `084 909 1786` (`+27 84 909 1786`) on homepage, Contact page, footer and Acrylic PVA product page.
- Our Story typography is consistent with the rest of the site.
- Replaced the unrelated city scene with a self-contained stylised Durban skyline graphic.
- Improved footer spacing and logo legibility.
- Added `product-acrylic-pva.html` as the master Maestro product detail-page design for later Shopify conversion.
- Technical values that have not been supplied by the client are clearly marked `To be confirmed` rather than invented.
